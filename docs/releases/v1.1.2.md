# GitTotte v1.1.2

## 主な変更

- PowerShellで次のコマンドを実行した際、最新の出力へ追従するようにしました。
- 実行状態と経過秒数を表示し、コマンド実行と途中入力の送信をCtrl＋Enterに統一しました。
- コマンド履歴から内容を入力欄へ戻して再実行できます。
- PowerShell停止・パネル非表示時にF5でGitHubの履歴を更新できます。
- 比較の改行判定を修正し、Gitの起動を一括化しました。
- 特殊なファイル名、機密ファイルの初期選択、失敗時の一時フォルダー処理を改善しました。
- 履歴の表示・取得を作業ルートとタグに絞りました。旧版のPR由来フォルダーの基準は保持します。
- 本体のMITライセンス、画像の利用案内、説明書と不具合報告の入口を追加しました。

## 更新方法

アプリを終了し、ZIPを別の場所にすべて展開してGitTotte.exeを起動してください。設定・登録済みフォルダー・自分用メモを引き継ぎます。

## 配布物

Windows用ZIP、SHA-256、同梱部品のソース、検査レポートを確認してください。コード署名はありません。初回の警告や端末ごとの動作は実機で確認してください。
