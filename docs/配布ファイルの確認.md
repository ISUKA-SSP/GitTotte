# 初回起動時の警告と配布ファイルの確認

GitTotteはコード署名なしのWindowsアプリです。初めてダウンロードするファイルの評判が十分に蓄積していない場合、ChromeやWindowsが警告を表示することがあります。表示や操作の可否は端末・組織の設定によって異なります。

## 配布元とファイルを確認する

公式リポジトリは https://github.com/ISUKA-SSP/GitTotte です。配布元として作者が案内したVectorのページも利用できます。

GitHubの配布ページには対象バージョンのZIPとSHA-256チェックサムを掲載します。PowerShellで次のコマンドを実行し、値を配布ページのチェックサムと比較できます。パスはダウンロードしたファイルに合わせて変更してください。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\GitTotte-1.1.2-Windows-x64.zip'
```

Defenderの検査結果も、対象版・ファイルのSHA-256と合わせて確認できます。検査結果と一致しても、すべての端末での動作や安全性を保証するものではありません。

## 「WindowsによってPCが保護されました」と表示されたとき

配布元とファイルを確認して利用する場合、SmartScreenの画面に「詳細情報」があれば開き、表示されたアプリ名・発行元を確認します。「実行」ボタンが表示される環境では、そのボタンから起動できます。署名のない版は発行元が不明と表示される場合があります。

マルウェア名を伴う検出や、組織のポリシーによるブロックが表示された場合は、警告の種類・対象ファイル・バージョンを確認し、作者や端末の管理者へ相談してください。GitTotteの通常利用に管理者権限は不要です。

## 報告するとき

「使い方・環境 → 不具合・要望を送る」から、警告の文面・対象ファイル・バージョンを報告できます。スクリーンショットにはユーザー名、メールアドレス、社内情報などが写っていないか確認してください。
